# arm6dof

## Việc cần làm
### Phần lựa chọn servo
- Tính moomen các khớp
- Tính lực kẹp của gripper
- Lựa chọn servo cho phù hợp
### Phần điều khiển
- Xác định bảng DH (nếu cần)
- Thiết lập phương trình quỹ đạo
- Lập trình điều khiển nhấc chai nước từ (x1,y1) đến (x2,y2)
- Lập trình điều khiển hành động rót nước
